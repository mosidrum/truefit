# TrueFit

TrueFit is a web app that helps you tailor a CV to a specific job.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The workspace is shown while `userLoggedIn` is `true` in `lib/session.ts`. Set that flag to `false` to see the landing page.

## Google sign-in
